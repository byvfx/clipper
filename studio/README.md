# studio/

The studio's working files, kept in git because they hold months of editorial judgement
(HANDOFF.md, "Back up the taste layer"), but not part of the clipper package:

- `mockups/`: cover and page mock-ups (the Enquirer look, the weekly, Sloth Beat, The Udder
  Truth's storyboards, scripts and reference frames). Large takes and renders are gitignored.
- `research_notes/`: notes behind decisions (cover research, Shorts strategy) and
  `streamers.json`, the people-and-channels list `clipper story` reads (`[paths] streamers`).
- `reports/`: the media-heavy pieces (the 8-Bit Guy explainer prototype and its Resolve
  exports, the Jer archive reports). The audits and analytics stay in `/reports`.
