# The Udder Truth (#58)

Development material for the weekly show. Large media (takes, renders, voice tests, full-size
images, animatics) stays local and is gitignored; the notes and small previews are in git.

| Path | What's there |
|---|---|
| brass_eye_formats.md | The whole Brass Eye series: episode skeleton, devices, a draft running order |
| cold_open_breakdown.md | The cold open and logo sting (the 2001 special intro, the 1997 titles) |
| mother_moo_voice.md | Mother Moo's voice and writing guide (use it for any of her scripts) |
| mother_moo/ | Her design: Runway options, the hero image, task ids (README) |
| scripts/ | Scripts and TTS reads: `throw_v1.md` (the first throw), the test take (read C, `test_take_read_v3.txt`, is the voice reference) |
| storyboards/ | Storyboards, one folder per board (README in each); full-size boards and animatics on the NAS under `\\192.168.0.155\docker\clipper\udder_truth\` |
| takes/recordings/ | The user's raw phone takes (.mov) |
| takes/bakeoff/, first_clip/, perform_*/ | Model bake-off, the first hand-stitched clip, `clipper perform` runs |
| voice/ | Voice auditions and test reads (working copies) |

On the NAS, under `\\192.168.0.155\docker\clipper\udder_truth\`, are the media we build from:
`storyboards/<board>/` (full-size boards and animatics) and `audio/<segment>/` (build mixes
and their reads).
